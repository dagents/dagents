## 缺陷分析：3 个 P0 未实现功能

### NEW-004: 对话侧栏缺少删除/重命名 (H-070~H-079) — 🔴 P0

**影响**：10条测试用例全FAIL。用户无法在侧栏删除或重命名对话。
**根因**：`chat-nav-sidebar.tsx` 对话项为只读 `<Link>`，没有hover操作按钮。
**修复方案**：
1. 对话项添加 hover 显示的操作图标（删除🗑 / 重命名✎）
2. 删除：弹出确认对话框 → DELETE /api/chats/:id
3. 重命名：标题变为 `<input>` → Enter保存 / Esc取消 → PATCH /api/chats/:id

### NEW-005: Agent详情页缺少编辑/删除/归档按钮 (D-030~D-033) — 🔴 P0

**影响**：4条测试用例全FAIL。Agent详情页是只读视图，无操作入口。
**根因**：`agent-detail-view.tsx` 没有渲染操作按钮组。
**修复方案**：
1. 详情页header添加「编辑」「归档」「删除」按钮
2. 编辑：切换到编辑模式或弹出对话框
3. 删除：确认对话框 → DELETE /api/agents/:id
4. 归档：PATCH visibility='archived'

### NEW-006: Agent选择器缺少"已安装CLI"中间层 (H-090/H-092) — 🔴 P0

**影响**：无法从对话页一键创建CLI Agent（E2E-003也受阻）。
**根因**：`agent-selector.tsx` 只渲染了 DB Agent（已有）和未安装CLI（灰色），没有"已安装但未创建"的中间层。
**修复方案**：
1. 对比 `/api/cli-runtimes`（available=true）和 DB Agent（kind匹配）
2. 已安装但无对应DB Agent的CLI → 显示为"点击创建"层
3. 点击 → POST /api/agents 快速创建 → 自动选中

### NEW-007: Daemon注册对话框 Escape无效 (DM-016) — 🟡 P1

**根因**：对话框缺少 keydown Escape 监听器。
**修复**：对话框容器添加 `onKeyDown={(e) => e.key === 'Escape' && close()}`
